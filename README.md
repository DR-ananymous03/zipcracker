# ZIP Cracker ULTIMATE

Interactive multi-core ZIP password cracker with native C engine.

## Features

- Native C engine (ZipCrypto + AES-256)
- Multi-core via multiprocessing
- Interactive mode (no arguments needed)
- Auto-resume with checkpoints
- Live progress + speed + ETA
- Streaming wordlists (100 GB+ supported)
- John-style rule files
- Mask and PRINCE attacks

## Quick Start

    python3 zipcracker.py

## Requirements

- Python 3.8+
- gcc or cc compiler
